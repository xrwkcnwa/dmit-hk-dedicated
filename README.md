## 先说清楚：DMIT 的"独立服务器"到底叫什么

DMIT 官网上的正式叫法是 Dedicated Instance，直译过来是"独享实例"。中文圈子里大家习惯直接叫独立服务器或者独享主机，说的其实是同一个东西。

它和 VPS 的差别不在虚拟化技术，而在资源归属。VPS 是一台物理机切出来的若干实例，你拿到的是分配给你的那几核几 G；独享实例是把硬件资源相对固定地分给你，同宿主机上别人跑什么，不太容易挤到你的资源。早期介绍这批机器的文章用过"半独立主机、独享硬件资源"的措辞，比"独立服务器"这个词更贴近实际情况。

需要有个心理准备：目前公开渠道能查到的独享实例档位全部在香港机房。洛杉矶、东京、圣何塞三个机房在售的主力还是 VPS，没有对应的独立服务器产品线。如果你要的是美国机房的独立主机，DMIT 这边暂时给不了。

## 独享带宽不限流量，和 VPS 的大带宽限流量是两条完全不同的路

这是选型时最容易搞混的地方。DMIT 在两个产品线上做了相反的取舍：

| 对比项 | 香港独享实例 | 香港 / 洛杉矶 VPS |
| --- | --- | --- |
| 带宽 | 20–100Mbps 独享 | 1–10Gbps 端口共享 |
| 月流量 | 不限量 | 有额度，从 500G 到 50T 不等 |
| 超量后 | 不存在超量这回事 | 优化线路降速不停机，T1 系列同样降速继续跑 |
| IPv4 数量 | 3 个起，最高 32 个 | 通常 1 个，高配机型给到 2–3 个 |
| 起步价格 | $218.98/月 | 香港 Pro $39.9/月，洛杉矶 T1 年付 $36.9 起 |

看懂这张表，选型基本就定了：

- 业务每天要吞吐几十 TB 数据，那 100Mbps 的独享口根本不够看，该去买大带宽 VPS；
- 带宽需求平庸但流量常年顶格，独享实例的账反而算得过来——不用担心哪个月视频被刷爆了直接降速；
- 需要多个出口 IP 做白名单、分流或站点隔离，VPS 那 1 个 IP 完全不够用，这才是独享实例真正值钱的地方。

换句话说，独立服务器卖的不是速度，是确定性和 IP 资源。

## 线路、IP 与防护

早期资料对这批机器的线路描述是：NTT 直连，电信和联通方向走 CN2，默认附带 DDoS 防护。香港机房到大陆的物理延迟本来就低，公开测评里香港节点往返大陆的延迟普遍落在 20–50ms 这个区间。

但这些描述都是几年前写的，网络资源调度会变，路由也会调。真实下单之前，建议用官方提供的 Looking Glass 测试页或者测试 IP，自己从常用的几条线路 ping 一遍、traceroute 一遍，看回程走的是不是你能接受的方向。花十分钟实测，比看任何测评文章都靠得住。

IP 这块值得多说一句。DMIT 的 VPS 有一条"IP 被墙后每 15 天可免费更换一次"的政策，独享实例不需要靠这个机制——它本身就给 3 个以上 IPv4，最高 32 个，单个地址出问题时有替换空间。对做站群、需要多站点独立 IP、或者要跟第三方系统做 IP 白名单对接的业务来说，这才是选择独享实例最实在的理由。

## 常见问题

**Q：流量真的是无限的？**
公开资料把独享实例列为不限流量，这一点比较明确。但"不限流量"不等于"不限速度"，带宽按档位独享 20–100Mbps，这就是天花板。流量随便跑，速度固定。

**Q：独立服务器和 VPS 哪个更值？**
看你缺的是带宽还是 IP。缺带宽买 VPS，缺 IP 和确定性买独享实例。两者价格差一个数量级，不是同一类需求。

**Q：能自己装 Windows 吗？**
购买流程里操作系统是可选项，具体能选到哪些以结算页实际给出的列表为准。

**Q：只有香港有独立服务器吗？**
就目前公开能查到的信息来看是的，美国洛杉矶、圣何塞和日本东京三个机房在售的是 VPS 产品线。需要美国独立主机的话，得去别处找。

**Q：20Mbps 够干什么？**
20Mbps 大约是每秒 2.5MB 的传输能力。跑轻量 API、邮件服务、后台同步、监控回传这类持续但量不大的业务没问题；拿它做文件分发或者视频中转就不合适了，选之前先算清自己的实际峰值需求。
